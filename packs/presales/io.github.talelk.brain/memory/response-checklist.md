# Tender response checklist

Used by the response writer and the analyst. Edit it to match how your firm answers.

## Before writing

- Read the whole terms of reference, including annexes, the model of the financial offer and any amendment (addendum).
- List the eliminatory criteria and the documents that must be in the envelope (administrative, technical, financial). A missing document disqualifies.
- Note the submission deadline with the time and place, the questions deadline and the bid validity.
- Decide go or no-go: do we meet the required references, certifications and turnover?

## Writing

- One answer per requirement, in the buyer's order and headings, quoting the clause number.
- Weigh effort by the evaluation weights.
- References, certifications, CVs and prices come only from the firm's records. Never invent them; mark a gap `[À COMPLÉTER]`.
- Same language as the terms of reference; same terms for the same thing throughout.
- State assumptions and exclusions.

## Before submission

- Every mandatory requirement answered; every form filled, stamped and signed where required.
- Financial offer consistent with the technical one; amounts and totals checked, currency and taxes stated.
- Validity period as asked. File names and format as asked.
- A person other than the writer has read it.
