# قالب شاشات التطبيق: مدخل واحد لكل تطبيق ويب

انسخ هذا المدخل لكل تطبيق ويب، وسمِّ النسخة `app-screens-<app>.md`، واستبدل كل ما بين الأقواس الزاويّة. يجد وكلاء الجولة هذه المدخلات بـ `memory.search` (يبحثون عن "app screens" واسم التطبيق). وما دام التطبيق بلا مدخل فلا يعرف المسح الأسبوعي ماذا يزور.

- الاسم: `<اسم التطبيق كما يقوله الناس>`

- اللغات: `<الإنجليزية، الفرنسية، العربية>`
- حساب الاختبار: `<اسم المستخدم، واسم السر الذي يحمل كلمة المرور؛ وليس حساب شخص حقيقي أبدًا>`
