## Schema additions must carry a DEFAULT (2026-11-11, `talelk/brain@` commit "Declare DEFAULT NULL on the new nullable ledger columns")
`scripts/repair-live-schema.ts` adds a missing column to an existing live table only when the schema file declares it with a DEFAULT; otherwise it refuses to realign and the deploy leaves the Governor container stopped. On 2026-11-11 track I2 added `missions.budget_tokens` and `mission_spend.accounting` without DEFAULT and the live Governor was down for several minutes until the schema file was fixed and redeployed. Rule: every new column on an existing table declares `DEFAULT` (use `DEFAULT NULL` for nullable). Deploy only from a tree whose schema diff has been checked for this.

## Deploy safety net (2026-11-11, track E2)
- `scripts/deploy-demo.sh` first copies the live databases out of the running Governor (tar over ssh, read-only) and runs this checkout's `scripts/repair-live-schema.ts` on the copy. A failure aborts BEFORE rsync, build or stop, so the old container keeps serving. It loads host, port and sudo password from `~/.config/brain-dev/credentials.env` when not in the environment (never printed). `BRAIN_DEPLOY_SKIP_PRECHECK=1` skips it. If the stop/repair/up sequence fails afterwards, the old container is started again; if the new one never becomes ready the first error lines of its log are printed.
- `tests/fixtures/released-schema/` holds the schema files of the last deployed build; `tests/contracts/live-schema-upgrade.test.ts` (part of `pnpm verify:fast`) upgrades databases built from it with the repair script and fails by name on a new column without DEFAULT. A successful deploy refreshes the fixture via `scripts/refresh-released-schema.sh`; commit it.
- Tests: `BRAIN_TEST_TIMEOUT_FACTOR=3 pnpm test:integration` scales waits under load; `pnpm test:integration|security|chaos` pick a private TMPDIR automatically (or use yours if set).

## Optional notification webhook (2026-11-11, ADR 0011)
Set `BRAIN_NOTIFY_WEBHOOK_URL` (https, or http on localhost) and optionally `BRAIN_NOTIFY_WEBHOOK_SECRET` in the Governor's environment to offer people the webhook channel. The body is a link only (`{type, kind, text, link, count?}`), signed with `x-brain-signature: sha256=<hmac>` when a secret is set. Unset means a safe no-op and the preference shows as unavailable. Share links use `BRAIN_BASE_URL` for their address.
